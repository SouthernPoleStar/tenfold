# 遗迹

模组会在地表自然生成三种**遗迹**，每座遗迹里守着一名 Boss，击杀后掉落对应的武器。结构由代码生成（不依赖 `.nbt` 模板），所以每次遇到的尺寸、朝向、轮廓都不一样。

| 遗迹 | 地形材质 | 守卫 | 击杀掉落 |
|---|---|---|---|
| **蜘蛛巢的屋顶** | 黑曜石地板 + 强化深板岩墙 | [里恩](Boss战#里恩) | **双蛇杖** |
| **铁栏寺** | 橡木木板地板 + 朱红色混凝土墙 + 黄色混凝土墙顶 | [雷横](Boss战#雷横) | **天退星刀** + **肩挂式弹药箱** |
| **蜘蛛巢的走廊** | 白桦木板地板 + 哭泣的黑曜石墙 | [马蒂亚斯](Boss战#马蒂亚斯) | **莱万丁** |

## 蜘蛛巢的屋顶

| 项 | 说明 |
|---|---|
| 尺寸 | **20×20 ~ 40×40**，横竖独立随机 |
| 轮廓 | 四角各自随机削掉 0~6 格，再随机挑一条边挖一道 1~4 格深的凹口 —— **不是固定正方形** |
| 地板 | **黑曜石** |
| 墙体 | **强化深板岩**，墙高 **4 格**，无顶盖 |
| 守卫 | **里恩**（7500 血） |
| 掉落 | **双蛇杖** |

场地是露天的"屋顶"式平台：黑曜石地面 + 一圈强化深板岩矮墙，内部会自动清空，不会被山体或树叶堵住。

## 铁栏寺

| 项 | 说明 |
|---|---|
| 尺寸 | **10×15** 长方形，随机决定长边朝向 |
| 地板 | **橡木木板** |
| 墙体 | **朱红色混凝土** |
| 墙顶 | 最顶一层为**黄色混凝土** |
| 墙高 | **5 格**（含顶端那层黄色） |
| 守卫 | **雷横**（8000 血） |
| 掉落 | **天退星刀** + **肩挂式弹药箱**（各一件） |

## 蜘蛛巢的走廊

| 项 | 说明 |
|---|---|

| 守卫 | **马蒂亚斯**（2000 血） |

## 生成规则

| 遗迹 | 群系 | 间距 / 间隔（区块） |
|---|---|---|
| 蜘蛛巢的屋顶 | 黑森林、森林、花森林、白桦森林、原始白桦森林、针叶林 | **44 / 16** |
| 铁栏寺 | 平原、向日葵平原、热带草原、热带高原、沙漠、恶地 | **52 / 18** |
| 蜘蛛巢的走廊 | 黑森林、森林、白桦森林、原始白桦森林、针叶林、原始松木针叶林、原始云杉针叶林 | **40 / 14** |

- 都是**地表结构**（`surface_structures`），地形不做额外平整，遗迹直接落在地表高度上。
- **老存档也生效**：结构只在**新区块**生成，已经生成过的区块不会补。
- 想快速找一座：

```
/locate structure tenfold:spider_nest_roof
/locate structure tenfold:iron_rail_temple
/locate structure tenfold:spider_nest_corridor
```

## Boss 与掉落

- 守关 Boss 生成时即被标记为**持久化**，玩家走远不会消失。
- Boss 在场地**中心**生成，落地位置已经避开了墙体。
- 掉落走**实体战利品表**（`data/tenfold/loot_tables/entities/`），所以：
  - 击杀遗迹里的 Boss 会掉；
  - 用**刷怪蛋**召唤的同一个 Boss 也照样掉。
- 掉落是**必掉**，不消耗运气，也没有玩家击杀条件限制。

## 机制提示

- 里恩会**每 10 秒换一次双蛇杖形态**，遗迹空间不大，注意他切成鞭子/长枪时的距离。
- 雷横在**血量 62.5% 以下**进入狂暴并召唤两个小弟，3 秒内杀掉小弟能让他虚弱 II。
- 马蒂亚斯的「过人的毅力」在高护甲、高血量下会拖很久，建议带高爆发武器一次打空 300 点耐久。

## 常见问题

**找不到遗迹？** 确认在对应群系（比如铁栏寺只在平原/沙漠/热带草原类群系），并用 `/locate structure` 检查。结构间距较大，走得远一点。

**遗迹被地形切了一半？** 结构落在地表高度上，陡峭地形可能让部分墙体和山坡交错。这是正常现象，战斗区域（内部清空区）仍然是完整的。

**Boss 不出来？** 只有在生成该遗迹的中心区块时才会生成 Boss；如果那次生成失败（极少数情况），日志里会有 `Failed to spawn ruin boss` 警告。
