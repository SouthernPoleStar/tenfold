# 安装与兼容

## 环境要求

| 项 | 要求 |
|---|---|
| Minecraft | **1.20.1**（`[1.20.1, 1.21)`，其它版本会拒绝加载） |
| Forge | **47.2.0 或更高**（`[47,)`），1.20.1 的 47.x 任意小版本都能跑 |
| Java | **17** |
| 安装侧 | **客户端 + 服务端都要装**（依赖声明 `side="BOTH"`，只装一边连不上） |

## 安装步骤

1. 用官方启动器或 HMCL/PCL 装好 **Forge 1.20.1**。
2. 打开 `.minecraft/mods/`，把 `tenfold-0.1.14.jar` 放进去。
3. **完全退出游戏再启动**——换 jar 之后不要只退回主菜单，Forge 不会重载已经载入的模组。
4. 启动后看模组列表里是否有「L·C Mod」，创造物品栏里是否有「L·C Mod」标签页。

服务端同理：把同一个 jar 放进服务端 `mods/`，客户端版本必须与服务端一致，否则会被踢出并提示模组不匹配。

## 多人联机

- 本模组**没有客户端专属逻辑**，但 Boss、指令、状态都由服务端结算；客户端负责渲染与 HUD。
- 版本必须完全一致（同一个 jar），只装服务端不装客户端会有物品/实体缺失。
- 专用服务器（paper 之类）**不支持**，必须是 Forge 服务端。

## 卸载

从 `mods/` 删掉 jar 即可。已经生成的 Boss 与 Poey 实体、玩家身上的自定义状态会随模组消失而失效；如果存档里含有本模组的物品，卸载后那些物品会变成「空气」或报 missing registry，**建议卸载前先把物品丢掉或备份存档**。

## 可能遇到的兼容问题

- **改血量上限的模组**：本模组在启动时用反射把原版 `generic.max_health` 的上限从 1024 抬到 1e7。如果另一个模组也改这个属性，两者可能互相覆盖，表现为 Boss 只有 1024 血。日志里搜 `Raised entity max-health limit` 可以确认是否生效。
- **改护甲渲染的模组**：神备套装、炎蝶之棺、假面都走 `getArmorTexture` 返回透明贴图来隐藏模型，和大部分护甲类模组不冲突；但某些光影/材质包可能把透明层重新画出来。
- **CustomSkinLoader / 皮肤模组**：无冲突。
- **性能模组**（Embeddium、Oculus 等）：一般无冲突，如果 Boss 渲染异常可先关光影再测。

## 从源码构建

```bash
# 需要 JDK 17
./gradlew build          # 产物：build/libs/tenfold-0.1.14.jar
./gradlew runClient      # 开发客户端
./gradlew runServer      # 开发服务端
```

Windows 下若 `JAVA_HOME` 没配，先把 JDK 17 的路径指过去再跑 `gradlew.bat`。
