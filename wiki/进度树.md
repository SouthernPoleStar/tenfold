# 进度树

共 **11 个进度**，根节点是拿到双蛇杖。结构上分三条线：指令线、莱万丁线，以及两个独立目标。

```
双蛇杖
├── 指令
│   └── 遵循指令之意
│       └── 指令成瘾        （挑战）
├── 指令是区              （挑战，违约三次）
├── 传说之剑              （莱万丁）
│   └── 是时候拆开一层包装纸了   （目标）
│       └── 连第二层包装纸都要打开吗？ （目标）
│           └── 莱万丁，完全解放   （挑战）
├── 恶魔的契约            （目标）
└── 守护他人的决意        （目标）
```

## 详细条件

| 进度 | 框架 | 条件 | 描述文本 |
|---|---|---|---|
| **双蛇杖** | 普通 | 锻造出双蛇杖 | 锻造一柄有十副面孔的武器。 |
| **指令** | 普通 | 第一次锁定指令目标 | 获得一个指令目标。 |
| **遵循指令之意** | 普通 | 完成 1 次指令（击杀目标） | 完成一次指令，并获得一次力量加成。 |
| **指令成瘾** | 挑战 | 连续完成 **4 次**指令 | 连续完成 4 次指令。永久渴望下一条指令。 |
| **指令是区** | 挑战 | 连续违约 **3 次**指令 | 连续违背 3 次指令。 |
| **传说之剑** | 普通 | 拿到莱万丁 | 就算遭到一些怀疑又能如何？那把传说之剑，已经在我手中了！ |
| **是时候拆开一层包装纸了** | 目标 | 莱万丁进入第 2 阶段 | 这把剑，永远都玩不腻。 |
| **连第二层包装纸都要打开吗？** | 目标 | 莱万丁进入第 3 阶段 | 哈哈，有意思，原来特色是这种手感。 |
| **莱万丁，完全解放** | 挑战 | 莱万丁进入第 4 阶段 | 这会很烫的，非常烫！ |
| **恶魔的契约** | 目标 | 拿到魔弹枪 | 不要踏入我的火线。除非你想成为这寄宿着恶魔的子弹的靶子。 |
| **守护他人的决意** | 目标 | 第一次喝下 IRA 完全解放药水 | 我定然是为了守护众多的同伴而挥剑。期望落空也好，没能救下所有人也罢 |

## 注意

- 「**指令成瘾**」和「**指令是区**」是互斥的两条路：前者要求连续完成 4 次，后者要求连续违背 3 次。违约会打断连杀，所以要分开刷。
- 「**守护他人的决意**」看的是**喝下药水**，不是捡到决意，拿到药不喝不会解锁。
- 莱万丁的三级进度对应**阶段**，重包装后重新拆开不会重复解锁（进度只触发一次）。
- 双蛇杖坍缩（违约 3 次）会同时解锁「指令是区」，并让你 3 分钟内只能用叉勺。
