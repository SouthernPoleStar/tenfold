# Poey

友方支援单位，跟着队伍跑的小型生物。物品 ID `tenfold:poey`，实体类型 `tenfold:poey`。

## 获取

工作台**无序合成**：恶魂之泪 + 鸡蛋 + 下界合金碎片 → **Poey 刷怪蛋**。

## 基础属性

| 项 | 数值 |
|---|---|
| 血量 | **1000**（500 颗心） |
| 回血 | 每 **4 秒 1 点**，像饱食度满的玩家一样自然恢复 |
| 跟随 | 生成后自动跟随最近的玩家（**24 格**内），距离超过 5 格会小跑跟上 |
| 坐下 | **右键**切换坐下 / 起身；坐下时不跟随、不攻击 |
| 抗性 | **免疫玩家造成的伤害**（不会被队友误杀） |

## 三个机制

### ① 救场

附近玩家血量 **< 5（2.5 颗心）**时自动触发：

- **生命恢复 V**（10 秒）
- **抗性提升 III**（10 秒）

冷却 **10 分钟**。

> 这是保命底牌，冷却很长，别指望它连救两次。

### ② 卑贱之物

Poey 命中敌人时，给目标挂 **10 秒**的「卑贱之物」：

- 目标**造成的伤害 -70%**
- 目标**受到的伤害 +110%**

全模组最强的易伤 Debuff。打 Boss 前先让 Poey 上去摸一下，全队输出几乎翻倍。

### ③ 脉动

Poey 每次命中获得 **1 层「脉动」**，最多 **10 层**，30 秒刷新。每层：

| 效果 | 每层 |
|---|---|
| 回血速度 | +20% |
| 移动速度 | +10% |
| 攻击伤害 | +30% |

所以 Poey 越打越快、越打越疼，也会自己回血。

## 使用建议

- **带去 Boss 战**：卑贱之物的 +110% 易伤配合高爆发（天退星刀标弹、天将拂晓）非常好用。
- **别让它挨打太多**：1000 血虽然厚，但 Boss 的伤害也不低；坐下可以把它留在安全区。
- **右键坐下**是唯一防止它跟着你冲进岩浆的办法。
- 刷怪蛋配方里的恶魂之泪是 1.20.1 的替代方案（原版没有「失水恶魂」），想换材料改 `poey_spawn_egg.json`。

## 排查

- **Poey 不跟随**：先右键看是不是被坐下状态锁住了（`Sitting` 标签）。
- **不打敌人**：坐下状态不攻击；另外它只会攻击对它有敌意的目标。
- **不回血**：脉动层数会过期（30 秒），且回血速度与层数挂钩，层数掉光就只剩基础速度。
