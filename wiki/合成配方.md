# 合成配方

分两类：**锻造台**（`smithing_transform`，模板 + 底物 + 附加）和**工作台**（`crafting_shaped` / `crafting_shapeless`）。

> 所有物品也能在创造模式的「**L·C Mod**」标签页里直接拿。

---

## 锻造台

锻造台需要**下界合金升级模板**位放指定物品，配方才能生效。

| 底物 | 铁剑 |

## 工作台

### 子弹

产出 **1 颗**。

| | | |
|---|---|---|
| · | **铁锭** | · |
| **铜锭** | **火药** | **铜锭** |
| · | **铜锭** | · |

合计：铁锭 ×1 + 铜锭 ×3 + 火药 ×1 → 子弹 ×1。

### 长剑

| | | |
|---|---|---|
| · | **铁锭** | · |
| · | **铁锭** | · |
| **铁锭** | **木棍** | **铁锭** |

合计：铁锭 ×4 + 木棍 ×1。

### 炎蝶之棺

| | | |
|---|---|---|

### Poey 刷怪蛋（无序合成）

| 材料 |
|---|
| 恶魂之泪 ×1 |
| 鸡蛋 ×1 |
| 下界合金碎片 ×1 |

三个材料放哪格都行。1.20.1 没有「失水恶魂」，所以用**恶魂之泪**替代；想换成别的物品，改 `data/tenfold/recipes/poey_spawn_egg.json` 即可。

## 酿造台

### IRA 完全解放药水

| 步骤 | 操作 |
|---|---|
| 1 | 粗制的药水（水瓶 + 下界疣） |
| 2 | 加入 **守护他人的决意** → IRA 完全解放药水 |
| 3 | （可选）加入**红石**延长持续时间 |

**守护他人的决意**的来源：被**驯服**的生物（狼、猫、马等）被**敌对生物**打死时掉落 ×1。

> 注意：必须是被敌对生物打死，玩家自己动手不会掉。驯一群狼放在刷怪塔旁边是最稳的量产方式。
