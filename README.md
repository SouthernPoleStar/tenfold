# 双蛇杖（Caduceus）

Minecraft **1.20.1 · Forge 47.x** 的单武器模组。一把武器拥有 **10 种形态**，通过「下达指令 → 击杀指令目标」来推进形态、获得力量；违约三次会让武器坍缩成叉勺并被锁定 3 分钟。

## 安装

1. 安装 **Minecraft Forge 1.20.1**（47.2.0 或更高）。
2. 把 `caduceus-1.0.0-mc1.20.1-forge.jar` 放进 `.minecraft/mods/`。
3. 单人游戏需要装 Forge，纯服务端/客户端都要装（`side="BOTH"`）。

## 获取方式

| 方式 | 说明 |
|---|---|
| 创造模式 | 「双蛇杖」标签页 |
| 锻造台 | 下界合金碎片（模板）+ 下界合金剑 + 回响碎片 |
| 指令 | `/give @s tenfold:tenfold_blade` |

## 操作

| 输入 | 行为 |
|---|---|
| **右键**（朝生物） | 选取 8 格内**最近的**玩家（联机）/ 怪物 / 中立生物作为「指令目标」 |
| **右键**（朝同一目标） | 刷新 30 秒倒计时，不重置连杀 |
| **右键**（朝空气/另一目标） | 视为**违约**（取消 / 换目标） |
| **潜行 + 右键** | 切换到下一形态 |
| **潜行 + 左键** | 切换到上一形态 |

指令目标会获得发光描边和「**指令目标**」状态，HUD 在快捷栏上方显示当前形态、连杀进度（金点）与违约计数（红点）。

### 指令目标（Buff）

被下达指令的生物立刻获得，持续 30 秒（与指令倒计时同步，刷新指令会顺带刷新 buff）：

| 效果 | 数值 |
|---|---|
| 受到双蛇杖的伤害 | **+90%** |
| 移动速度 | **-50%**（原版缓慢 Ⅳ） |
| 攻击手持双蛇杖的玩家 | 所造成伤害 **-20%** |
| 视觉 | 发光描边 + 状态图标 |

## 规则

- **3 连杀 = 1 层力量**：指令目标连杀 3 次后，形态自动前进一格，并获得原版 **力量（Strength）** Ⅰ 级。每完成一轮再叠一级，最高力量 Ⅴ，持续 120 秒。
- **违约 = 1 层虚弱**：切换目标、主动取消、超时未杀、杀错对象都会记一次违约，并获得虚弱。
- **3 次违约 = 坍缩**：武器强制变成叉勺，并被锁定 **180 秒**。锁定期间不能切形态、不能下达指令，但可以正常挖土。倒计时结束后恢复到「大剑」并清空违约计数。

## 进度

本模组新增一棵独立的进度树（根节点：拿到双蛇杖）。四个进度全部由**自定义触发器**驱动，条件里的 `count` 就是判定阈值：

| 进度 | 图标 | 获得条件 | 触发源 | 类型 |
|---|---|---|---|---|
| **指令** | 双蛇杖 | 第一次锁定指令目标 | `tenfold:contract_issued` | 普通 |
| **遵循指令之意** | 铁剑 | 完成 1 次指令（连杀 3 只），同时获得力量 | `tenfold:contract_done` `count: 1` | 普通 |
| **指令成瘾** | 海洋之心 | **连续**完成 4 次指令 | `tenfold:contract_done` `count: 4` | 挑战 |
| **指令是区** | 屏障 | **连续**违背 3 次指令 | `tenfold:contract_broken` `count: 3` | 挑战 |

> 「连续」的计数是分开的：完成一次指令会把违约连击清零，反过来违约也会把完成连击清零。所以两个挑战进度互斥推进。

## 药水：IRA完全解放

这条链路不靠指令，靠一个被守护者换来的东西。

### 第一步：守护他人的决意（物品）

1. **驯服**任意一个可驯服的生物（狼、猫、马、鹦鹉……）。
2. 让它**被敌对生物打死**（僵尸、骷髅、蜘蛛等 `Enemy` 类生物）。
3. 它倒下时会掉落 **1 个「守护他人的决意」**，并用红字提示主人。

> 判定很严：必须是**敌对生物**造成的死亡。玩家击杀、岩浆、摔落、火焰都不掉——这是「战死」才配得上的东西。
> 掉落原数量固定为 1，不受抢夺影响。

### 第二步：炼药

在酿造台里：

| 基底 | 材料 | 产物 |
|---|---|---|
| 粗制的药水（Awkward） | 守护他人的决意 ×1 | **IRA完全解放药水**（3 分钟） |
| IRA完全解放药水 | 红石 | **IRA完全解放药水（延长）**（8 分钟） |

喷溅、滞留、药箭同样适用（把药水换成对应容器即可）。

### 第三步：首次饮用 → 进度「守护他人的决意」

第一次喝下这款药水时解锁进度，图标同样是那张红色双剑，边框为 **goal**（金框），并默认隐藏（未达成前看不见）。

> 描述：**我定然是为了守护众多的同伴而挥剑。期望落空也好，没能救下所有人也罢**

### IRA完全解放（Buff）

由「守护他人的决意」酿造的药水提供（见上一节），也可以用指令 `/effect give @s tenfold:ira_release <秒数>` 直接获得：

| 效果 | 数值 |
|---|---|
| 死亡免疫 | 致命一击永远保留半颗心，**不会死亡** |
| 造成伤害 | **+90%** |
| 受到伤害 | **-70%** |
| 伤害清算 | 期间每次实际受到的伤害会记账；效果结束后**一次性结算总额 ÷ 10** |

> 清算是延迟到 buff 结束后的一笔 magic 伤害，所以把 buff 拖得越长越划算；如果结束时那笔清算足够大，仍然可能被打死——这是故意的。
> 下线重进会计账保留；切换到创造/旁观会正常失去效果。

### 指令成瘾（Buff）

连续完成 4 次指令时立刻获得，同时该进度的 `rewards.function` 也会再补一次（`data/tenfold/functions/grant_addiction.mcfunction`）：

| 属性 | 值 |
|---|---|
| 名称 | **指令成瘾** |
| 类型 | 增益（紫色） |
| 效果 | **攻击力 +10** |
| 持续 | 300 秒（5 分钟） |
| 实现 | 原版属性修饰符，加在 `ATTACK_DAMAGE` 上，走瞬时修饰符通道 |

第 4 次完成后连击计数会归零，想再拿就得再连续完成 4 次。

## 十种形态

伤害是**绝对数值**：物品的攻击力属性按当前形态动态替换（`getAttributeModifiers`），所以物品栏里显示的数字、tooltip 写多少、实际打多少，三者一致。

| # | 形态 | 伤害 | 特性 |
|---|---|---|---|
| 0 | 大剑 | 13 | 60° 扇形横扫，最多 3 个额外目标 |
| 1 | **镰刀** | **15** | 击杀时割倒周围 2 格内的其他单位（最高） |
| 2 | 刺剑 | 9 | 3 秒内连续命中叠加伤害（最多 4 层 ×12%） |
| 3 | 斧子 | 12 | 命中禁用对方盾牌 8 秒 |
| 4 | 锤子 | 14 | 减速 II、强击退 |
| 5 | 鞭子 | 8 | 5.5 格超长距离，命中拉近目标 |
| 6 | 半手剑 | 10 | **格挡时伤害减半并反弹 30%** |
| 7 | 长枪 | 12 | 正前方直线穿刺 |
| 8 | 锥子 | 11 | 无视 50% 护甲 |
| 9 | **叉勺** | **6** | 惩罚形态，可正常挖掘（最低） |

## 开发

```bash
# 需要 JDK 17
./gradlew build          # 产物在 build/libs/
./gradlew runClient      # 开发客户端
./gradlew runServer      # 开发服务器
```

首次构建会下载 Forge MDK 依赖，约 1–3 分钟。

### 目录结构

```
src/main/java/com/tenfold/
├── Tenfold.java                 模组入口，注册物品/效果/音效/创造页/进度触发器
├── ModItems / ModEffects / ModSounds / ModTabs
├── item/
│   ├── TenfoldBladeItem.java    物品本体：交互、命中、tooltip、挖掘、动态伤害属性
│   ├── WeaponForm.java          十种形态的枚举与数值
│   ├── WeaponData.java          NBT 状态读写（形态/连杀/违约/锁定/目标）+ 玩家级计数器
│   └── FormAbilities.java       各形态命中特效
├── common/
│   ├── ContractManager.java     指令核心逻辑（选取、判定、奖惩、退化、成瘾发放）
│   ├── ContractTriggers.java    三个自定义进度触发器
│   └── CommonEvents.java        成瘾属性、半手剑格挡、每秒判定、击杀登记
└── client/
    ├── ClientEvents.java        输入拦截 + 本地乐观切换
    ├── HudRenderer.java         快捷栏上方状态条
    └── ClientSetup.java         FOV 微调
```

数据文件：

```
src/main/resources/
├── data/tenfold/advancements/   root + 4 个进度
├── data/tenfold/functions/      grant_addiction.mcfunction
├── data/tenfold/recipes/        锻造台配方
└── assets/tenfold/              模型、贴图（形态 10 张 + 2 张状态图标）、语言文件
```

### 调参位置

- 数值：`WeaponForm` 枚举的构造参数（伤害 / 攻速 / 触及 / 挖掘速度），伤害单位是**点**（2 点 = 1 颗心）
- 规则常数：`WeaponData.STREAK_GOAL`、`BREACH_LIMIT`、`CONTRACT_TIMEOUT_TICKS`、`DEGRADE_TICKS`、`ADDICTION_CHAIN`
- 成瘾加成：`CommonEvents.ADDICTION_BONUS` 的修饰符数值（默认 `+10`），持续时间在 `ContractManager.onContractCompleted`
- 选目标范围：`ContractManager.TARGET_RANGE`

## 已知限制

- 十种形态共用一张贴图的模型结构，视觉差异来自 10 张独立 16×16 像素图（`textures/item/blade_0..9.png`），可以直接替换成你自己的美术资源。
- 形态切换靠 `inventoryTick` 写 `CustomModelData`，因此**首次进入世界时需要手持一 tick 才会切换贴图**（不会影响任何数值）。
- 联机时**其他玩家**也可以被选为指令目标（创造/旁观模式玩家除外，且遵循原版 PVP 规则（队友、gamerule 等））；怪物与中立生物（僵尸猪灵、蜜蜂、狼等）照常可选；被动动物（牛、羊）不会被选为目标，误伤也不算违约。
- 指令进度的判定挂在 `LivingDeathEvent` 上，且要求**近战直击致死**（`getDirectEntity` 必须是玩家）。用弓箭补刀、或目标被火烧死，都不算完成指令——这是刻意的，否则很容易刷。
